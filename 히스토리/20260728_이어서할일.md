## 6. 오늘 밟은 함정 (같은 데 또 빠지지 말 것)

| 함정 | 내용 |
|---|---|
| **build/ 산출물 삭제** | CSS가 안 바뀌면 빌드가 **같은 해시로 재사용**한다. 방금 빌드한 파일을 "구버전"인 줄 알고 지우면 404. index.html이 참조하는 것만 남기고 지울 것 |
| **JSX flex 공백 삼킴** | `display:flex` 셀 안에서 `"국내산" + <b>멸치</b>` → **"국내산멸치"**. 공백 텍스트 노드가 flex 아이템이 안 된다. 내용을 `<span>`으로 감쌀 것 |
| **JSX 속성 자리 주석** | `<Item {/* 주석 */} prop=... />` 는 파스 에러. 태그 위나 `/* */`로 |
| **스크립트 puppeteer 경로** | `_*.mjs`가 `projects/nip_landing`을 봤는데 그 폴더가 `2026billion_20260130_niplanding`으로 개명됨. 오늘 고쳐놨음 |
| **fullPage 스크린샷** | 긴 페이지에서 거짓 결과. `_shot.mjs`는 뷰포트 단위로 찍는다 |
| **폰트 서브셋** | 카피 바꾸면 `python _font_pretendard.py` 다시 돌릴 것. 빠진 글자는 대체 폰트로 떨어진다 |
