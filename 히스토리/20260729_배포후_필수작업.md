## 🟠 3. 메타 픽셀 — ID 발급 + 도메인 인증

3단계 진행 중이었다(2026-07-29 기준 **미완**).

```
① https://business.facebook.com/events_manager
   → 데이터 소스 연결 → 웹 → 이름 '산방식당 랜딩' → 직접 설치
   → 픽셀 ID(숫자 15~16자리)를 app/src/lib/ui.tsx 의 META_PIXEL_ID 에 입력

② ⭐ 도메인 인증 (이걸 빼먹으면 픽셀이 반쪽이 된다)
   이벤트 관리자 → 비즈니스 설정 → 브랜드 가치 보호 → 도메인
   → 추가 → sanbangjeju.com
   → 인증 방법은 DNS TXT 가 제일 쉽다 (Cloudflare 를 쓰므로)
      Cloudflare → sanbangjeju.com → DNS → 레코드 추가
      유형 TXT / 이름 @ / 내용 = 메타가 준 facebook-domain-verification=… 문자열
   → 저장 후 메타로 돌아와 '인증' 클릭 (전파에 몇 분~1시간)

③ 인증되면 총 이벤트 우선순위(AEM)에서 `Lead` 를 1순위로 올린다
```

확인: Chrome 확장 **Meta Pixel Helper** 로 `PageView`·`Lead` 발화 확인.

## 🟠 4. Cloudflare 엣지 캐시 규칙

현재 응답 헤더가 `cache-control: max-age=600` 이고 엣지 캐시가 사실상 안 걸려 있다.
이미지·폰트가 매번 원본까지 다녀오면 광고 유입에서 첫 화면이 느려진다.

```
Cloudflare 대시보드 → sanbangjeju.com → Rules → Cache Rules
  호스트 sanbangjeju.com → Edge TTL 1년 / Browser TTL 1년
```
무료 플랜에서 가능하다.

> ⚠️ 캐시를 길게 걸면 **다음 배포가 반영이 안 되어 보일 수 있다.** 배포 후에는
> Cloudflare 에서 `캐시 삭제(Purge Everything)` 를 한 번 눌러 줄 것.
> (JS/CSS 는 파일명에 해시가 붙어 자동으로 갈리지만, index.html 과 이미지는 아니다)
