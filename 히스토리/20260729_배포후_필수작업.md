## 🟠 2. 메타 — `Lead` 를 이벤트 우선순위 1위로

GA4와 같은 이유로 아직 목록에 없을 수 있다(이벤트 반영 대기).

```
이벤트 관리자 → 데이터 세트 '산방식당 랜딩'(2201863730547524)
→ 설정 탭 → 총 이벤트 측정 / 웹 이벤트 구성
→ Lead 를 맨 위(1순위)로 올리고 저장
```

**왜 필요한가:** 아이폰 사용자는 애플 정책상 메타가 이벤트를 8개까지, 우선순위
높은 것부터만 받는다. 우리가 쫓는 건 `Lead`(문의 폼 제출) 하나뿐이라 이게
1순위여야 아이폰 유입 문의도 광고 최적화에 반영된다.

**확인 방법:** Chrome 확장 `Meta Pixel Helper` 로 `PageView`·`Lead` 발화 확인.
또는 이벤트 관리자의 **`이벤트 테스트`** 탭에 `sanbangjeju.com` 을 넣으면
실시간으로 보인다.

## 🟠 3. Cloudflare 엣지 캐시 규칙

현재 `cache-control: max-age=600` 수준이라 엣지 캐시가 사실상 안 걸려 있다.
광고 유입에서 첫 화면 속도에 직접 영향을 준다.

```
Cloudflare → sanbangjeju.com → Rules → Cache Rules
  호스트 sanbangjeju.com → Edge TTL 1년 / Browser TTL 1년   (무료 플랜 가능)
```

> ⚠️ 캐시를 길게 걸면 **다음 배포가 반영 안 되어 보인다.** 배포할 때마다
> Cloudflare 에서 `캐시 삭제(Purge Everything)` 를 눌러야 한다.
> JS/CSS 는 파일명에 해시가 붙어 자동으로 갈리지만 `index.html` 과 이미지는 아니다.
