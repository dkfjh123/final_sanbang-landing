## ✅ 헷갈리는 것 — 이건 괜찮다

| 표현 | 판정 | 이유 |
|---|:---:|---|
| 비교표에서 **"부산식 = 돼지뼈·사골"** | ✅ | **부산식을 설명하는 문맥**이라 정상. 산방을 사골이라 하면 안 되는 것 |
| **"지난 10여 년간 가맹사업을 비롯해 다양한 방식으로…"** | ✅ | 공정위 등록 사실과 **모순되지 않는다**. 오히려 안전한 표현 |
| **"제주에서는 진행하지 않습니다"** | ✅ | 사실이고, 희소성·상권보호 메시지로 강력 |
| **"로열티 0원"** | ✅ | 브랜드를 안 주므로 사실. 단 "가맹 아님"과 붙여서 단정하지 말 것 |
| **"2개월 이내 100% 환불"** | ✅ | 원고에 명시된 조건 |
| **"스펙 지정 가능 / 대표가 직접 온다"** | ✅ | 최강 어필. 공개 허용 항목 |
| **공식 브랜드 파트너 트랙의 "산방식당 이름 사용"** | ✅ | **프리미엄 트랙은 실제로 브랜드·IP를 공유한다** (동래정·CJ프레시웨이가 사례). 금지 대상은 ①메뉴솔루션 트랙에 간판을 주는 것 |
| **"이력 있는 브랜드육을 씁니다"** | ✅ | 브랜드육 사용 자체는 공개 가능 |

## ✅ 생면 스펙 — 2026-07-27부로 사용 가능

> 제조사는 **협력업체**이고 자료를 직접 받았다. **업체명 표기는 불필요하되, 내용·수치는 제약 없이 사용 가능.**

가수율 **45% 이상** (일반 30~35%) · 다가수면 · 자연 숙성 · 최적 배합비 · 정제수 · 코셔 천일염 · HACCP · 생면 제조 **30년**

> 단, [위 금지선](#-절대-쓰면-안-되는-말)의 **"매일 뽑는 / 직접 뽑은"** 표현은 여전히 금지. 매장 제면으로 오인된다.

## 🟡 조건부 — 확인 후 사용

| 항목 | 조건 |
|---|---|
| 한만두 실명 | 공급관계 확인 후에만. 스펙("국내산 냉장육 100%")만 쓰는 건 상대적으로 안전 |
| 브랜드육 실명 (도드람·선진 등) | 해당 사 협의 후. 우선 "국내 대형 브랜드육" |
| 다수 프랜차이즈 공급 이력 | 🟡 자제. 쓰더라도 "다수 외식 브랜드에 공급 중인 생산라인" 수준 |
| 돈까스 AI 생성 이미지 | 실제 공급 제품과 괴리 없는지 확인 |

## 🧪 배포 전 검수 명령

```bash
# 금지어 스캔 (빌드 산출물 + 소스)
grep -o "가맹비\|가맹 아\|백년가게\|TOP10\|매출 보장\|사골\|컴포넌트\|H마트\|민들레\|다선\|매일 뽑\|직접 뽑\|자가제면" \
  build/*.js index.html app/src/**/*.tsx
```

> 히트가 나면 **문맥을 확인**할 것. 기계적으로 지우지 말고 어느 쪽을 설명하는 문장인지 본다.
>
> | 단어 | 정상인 경우 | 문제인 경우 |
> |---|---|---|
> | `사골` | 부산식을 설명하는 문맥 | 산방 육수를 사골이라 함 |
> | `원팩` | "원팩의 함정"을 비판하는 문맥 | 우리 제품을 원팩이라 부름 |
> | `자가제면` | 본점 브랜드 스토리 | 파트너 공급 설명 |
> | `가수율` | ✅ 이제 전부 정상 (사용 허용) | — |
