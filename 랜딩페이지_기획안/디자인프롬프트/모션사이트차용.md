This is NOT a full landing page.
Create only one self-contained section that presents five problems faced by

The section should retain the current 3-column, 2-row card structure, but upgrade

PAGE CONTEXT

산방식당 is a long-established Jeju restaurant brand founded in 1971.

This section is aimed at independent restaurant owners who:

- Do not want to join a franchise
- Want to operate under their own brand
- Need a differentiated menu
- Need a standardized recipe
- Want an additional signature menu that can generate sales

산방식당’s proposed solution is to provide one proven menu system based on its
55-year-old broth, sauce, and noodle production know-how.
