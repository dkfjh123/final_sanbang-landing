## ⚙️ 에셋 처리 규칙

| 규칙 | 내용 |
|------|------|
| 포맷 | 사진 → **WebP** / 영상 → **MP4 무음 루프** (GIF 금지) |
| 무게 기준 | 첫 화면 **≤ 2.2MB**, 전체 스크롤 **≤ 5MB** |
| 검증 | `node _weigh.mjs <url>` — 실제 전송량 측정 |
| 스크린샷 | `node _shot.mjs` — **뷰포트 단위**로 찍는다 (fullPage는 긴 페이지에서 거짓 결과) |
| 재생성 | `_optimize.mjs`의 jobs 배열 수정 → `npm run optimize` |

> 📌 참고 (이전 최적화 실적): 사진 20종 639.6MB → 3.45MB / 히어로 영상 139.7MB → 671KB / 줄서기 GIF 62.4MB → 0.96MB MP4
