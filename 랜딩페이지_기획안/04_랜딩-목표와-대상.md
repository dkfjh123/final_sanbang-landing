## 🎯 이 페이지의 정체

> **광고·SNS를 보고 들어온 사람이 문의를 남기게 만드는 리드 생성 페이지다.**

```
메타/네이버 광고 · 인스타 · 유튜브 등
            ↓
     【이 랜딩페이지】  ← 여기가 첫 접점. 이 사람은 산방식당을 잘 모른다.
            ↓
   ① 이게 뭔지 이해 → ② 진짜인지 납득 → ③ 나한테 맞는지 판단
            ↓
     문의 폼 작성 → dkfjh1234@gmail.com
```

> ⚠️ **2026-07-27 정정**: 이전 기획에 있던 `콜드메일 → 15분 통화` 전제는 **이 프로젝트에서 완전히 무시한다.**
> 그 전제에서는 "이미 메일을 읽은 사람"을 가정했기에 설명을 줄여도 됐지만, **지금은 아무것도 모르는 사람이 광고를 보고 들어온다.**
> → **페이지가 스스로 처음부터 끝까지 설명해야 한다.** 맥락을 아는 척하고 시작하면 안 된다.

### 이 차이가 만드는 설계 변화

| | 콜드메일 전제 (폐기) | **광고·SNS 유입 (현재)** |
|---|---|---|
| 방문자 상태 | 이미 제안을 읽음 | **아무것도 모름** |
| 페이지 역할 | 신뢰 검증 (도망 방지) | **인지 → 설득 → 전환 전부** |
| 상단 필요한 것 | 사실 증명 | **"이게 뭔지" 3초 안에** |
| 성공 지표 | 통화 승낙 | **문의 폼 제출 수** |
| 길이 | 짧아도 됨 | **끝까지 설득 구조 필요** |

### ① 기존 식당 운영자 — 시그니처 메뉴 도입 희망 ⭐ 주력

| | 내용 |
|---|---|
| 상태 | 매장은 돌아가는데 **'대표 메뉴' 한 방이 없다** |

### ② 기존 식당 운영자 — 검증된 밀냉면·밀면을 받아 쓰려는 사람 ⭐ 주력

### ③ 식당 창업 예정자 — 프랜차이즈는 싫은 사람 ⭐ 주력

> ⚠️ **이전 기획에서 제외했던 대상이나, 2026-07-27 사용자 지시로 다시 포함.**

| | 내용 |
|---|---|
| 상태 | 창업하고 싶은데 **프랜차이즈에 묶이기는 싫다** |
| 원하는 것 | **아무런 강제 요소 없이 자유롭게** 검증된 메뉴만 |
| 두려운 것 | 로열티, 5년 계약, 인테리어 강제, 본사 통제 |

> 🔴 **주의**: 이 대상은 "산방식당 간판을 달 수 있나요?"를 반드시 묻는다.

> → 따라서 **페이지에서 미리, 명확하게, 그러나 매력적으로** 처리해야 한다.
> 숨기면 문의 응대에서 매번 실망으로 돌아온다.

## 🚫 ① 트랙에서 간판을 주지 않는 이유 — 2중 방어선

주력 대상(①②③⑤)에게 가장 조심스럽게 다뤄야 할 지점.

| 이유 | 내용 | 대외 표현 |
|---|---|---|
| **① 가맹사업법** | 영업표지 + 통제 + 가맹금 = 가맹사업. 간판을 주면 그 순간 성립 | 언급 안 함 (내부 근거) |
| **② 동래정 콜라보** | 산방식당 브랜드는 현재 **동래정 백탄직화와 공식 콜라보** 중 → 같은 급의 브랜드 부여를 제3자에게 중복 불가 | 필요 시에만, 담백하게 |

### 이걸 약점이 아니라 강점으로 뒤집는 법

```
❌ "죄송하지만 간판은 못 드립니다"
✅ "간판을 드리지 않습니다. 그래서 로열티도 없습니다."
```

| 우리 구조 | 가맹 요건 판정 |
|---|:---:|
| 영업표지(산방식당 간판) 사용 | ❌ **주지 않는다** ← 방어선 |
| 통제 | ❌ 없다 (전부 자율) |
| 가맹금 | ❌ 없다 (로열티 0원, 상품 대금만) |

> **브랜드를 안 줬으니 브랜드 사용료를 받을 근거도 없다.** 이게 로열티 0원이 가능한 진짜 이유다.
> 카피: **"'간판'이 아니라 '무기'를 드립니다."**

## ⭐ 제주 제외 원칙

> 사용자 지시: *"신비스럽게 — **제주지역에서는 진행하지 않습니다**" (기존 가맹점 보호 및 산방식당의 희귀성 보전)*

| 효과 | 설명 |
|---|---|
| **희소성** | 아무한테나 주지 않는다 = 받는 쪽이 선택받은 느낌 |
| **기존 보호** | 제주 기존 매장·가맹점 상권을 지킨다 → 의리 있는 본사 |
| **원본 정합성** | "제주에서는 제주의 가치를 지키고, 육지에서는 그 깊이를 나눕니다"와 완벽히 일치 |
| **법적 안전** | 육지 한정 = 제주 기반 등록 가맹사업과 선을 긋는 효과 |

**표현 톤 — 담백하게, 변명 없이 한 줄로.** 길게 설명할수록 약해진다.

```
제주에서는 진행하지 않습니다.
제주의 가치는 제주에서 지킵니다.
```

> 배치: 문의 섹션 **바로 위**. 마지막에 걸리는 '조건' 하나가 오히려 신뢰를 만든다.
