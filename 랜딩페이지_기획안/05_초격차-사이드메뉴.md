## 📍 섹션의 위치와 역할

```
… ⑤ 확장 메뉴 (고기국수·제육덮밥·만두국…)
        ↓
   ▶ 【이 섹션】 초격차 사이드 — 돈까스·제육
        ↓
   ⑥ 묶이지 않는다 (자율)
        ↓
   ⑦ 제주 제외
        ↓
   ⑧ 문의
```

**역할**: 밀면만으로는 못 채우는 구멍을 메우는 **"마지막 킥"**.
앞 섹션들이 "맛이 진짜다"를 증명했다면, 이 섹션은 **"그런데 1년 내내 장사가 되나?"**에 답한다.

## ⭐ 이 섹션이 푸는 진짜 문제 — 밀면집의 계절성

> **밀면은 여름 장사다. 겨울에 죽는다.**

| 계절 | 밀면 | 사이드 (돈까스·제육) |
|---|---|---|
| 여름 | 🔥 성수기 | 보조 |
| **겨울** | ❄️ **급락** | 🔥 **매출 방어선** |

> **즉 사이드메뉴는 '있으면 좋은 것'이 아니라 '없으면 겨울에 문 닫는 것'이다.**
> 그리고 밀면+돈까스는 부산 밀면집의 **사실상 표준 조합**이다 — 억지로 붙이는 게 아니다.

**섹션 헤드라인 후보** (원문 영업 멘트에서):
> *"밀면만 하면 겨울에 어떻게 버티실 겁니까?"*
> *"사이드를 붙이셔야 하는데, **아무 냉동 돈까스나 넣으면 손님이 압니다.**"*

## 🎯 "초격차"의 정의 — 이 섹션의 핵심 개념

> 사용자 지시: *"'초격차'의 정의를 진행"*

### 좌표로 보면

```
    맛·퀄리티
        ↑
    높음│  (비어있음)          ★ 초격차
        │  생고기 직접 손질      브랜드육 + 스펙 지정
        │  (손 많이 감,         (재료가 다르다)
        │   숙련 필요)
        │
    중간│                     일반 냉동 완제품
        │                     (편한데 어디나 같은 맛)
        │
        └────────────────────────────────→
          낮음              높음    조리 편의성
```

> ### **초격차 = 매장에서 재현하기 쉬운 형태를 유지하면서, 재료와 스펙으로 격차를 만든 자리.**
> **지금 시장에서 이 우상단은 비어 있다.**

📌 이 문장이 섹션의 정의 블록이다. 좌표 그래픽으로 시각화하면 강력하다.

### 품목별 차별화

| 품목 | 일반 시장 | **초격차 버전** |
|---|---|---|
| **돈까스** | 수입 냉동 성형육, 얇은 두께, 범용 빵가루 | **브랜드육 부위 지정** + 두께 스펙 + 염지 배합 + 빵가루 차별화 |
| **제육** | 냉동 슬라이스 + 범용 양념 | **부위 지정 + 전용 양념 배합** (산방식당 전용) |
| 공통 | "어디서 먹어도 같은 맛" | **"여기서만 먹을 수 있는 맛"** |

> 💡 이 대비 구조는 [03 메뉴와 재료](03_메뉴와-재료.md)의 "범용 원팩 vs 산방 베이스"와 **똑같은 논리**다.
> 페이지 전체가 하나의 주장으로 관통된다 → **"범용으로는 안 나온다."**

## 🥩 브랜드육 — 별도 섹션으로 뽑을 것 (2026-07-27 지시)

> 사용자 지시: *"**브랜드육 전문**으로. 브랜드육의 장점을 뭔가 어필하는 섹션이 들어가면 좋겠다.
> **브랜드육을 그 어떤 곳보다 경쟁력 있게 만나볼 수 있다**라는 컨셉."*

### 컨셉 한 줄

> # "브랜드육을,<br>어디보다 경쟁력 있게."

파트너 표기는 **"브랜드육 전문"** — 업체명은 쓰지 않는다.

### 브랜드육이 뭐가 다른가 (사장님이 잘 모르는 영역)

| | 일반 돈육 | **브랜드육** |
|---|---|---|
| 이력 | 원산지만, 뭉뚱그려짐 | **어느 농장·어떤 사육 방식인지 추적 가능** |
| 품질 편차 | 로트마다 다름 | **등급·규격이 관리됨** |
| 이름 | 없음 | **이름이 있다** (도드람·선진 등 국내 대형 브랜드육) |
| 손님에게 | 말할 게 없음 | **메뉴판에 쓸 수 있는 근거가 된다** |

> 💡 **이 섹션의 숨은 역할**: 사장님은 육가공 스펙을 잘 모른다.
> 정보 비대칭을 우리가 채워주는 것 자체가 신뢰가 된다 → "이 사람들은 고기를 안다."

### 왜 우리가 더 경쟁력 있나

| 일반 소싱 | **우리** |
|---|---|
| 공장이 만든 것 중에서 **고른다** | **원하는 스펙을 지정해서 만든다** |
| 원산지·부위가 뭉뚱그려짐 | **브랜드육** — 이력이 있고 이름이 있다 |
| 스펙 변경 불가 | 부위·두께·염지·빵가루 **전부 조정 가능** |
| 소량이면 단가가 안 나옴 | **브랜드육 전문 파트너의 물량**으로 단가를 만든다 |

> ⚠️ 도드람·선진 등 **실명은 해당 사 협의 전까지 쓰지 않는다.** → "국내 대형 브랜드육"
> ⚠️ 원가·마진 수치는 랜딩에 절대 넣지 않는다. 1:1 영업자료로만.

## 💪 왜 우리가 이걸 할 수 있나 (남들은 못 함)

### ① 브랜드육 공급망 — 초격차의 원천

**브랜드육 전문** 파트너는 국내 대형 브랜드육 업체와 밀접한 관계다.
→ **브랜드육을 통해 어떤 스펙의 돈까스도 공급 가능하다.**

### ② ⭐ 고기업체 대표가 직접 온다 — 숨은 최강 무기

> **프랜차이즈에서는 공급업체 대표를 평생 못 만난다.** 슈퍼바이저가 오고, 문제가 생기면 본사 창구를 거친다.

| | 프랜차이즈 | **우리** |
|---|---|---|
| 만나는 사람 | 슈퍼바이저 (전달자) | **고기업체 대표** (결정권자) |
| 스펙 변경 요청 | 본사 → 물류 → 공장 (몇 달) | **대표에게 바로 말한다** |
| 문제 발생 시 | 창구 접수 | 대표가 직접 본다 |
| 우리 매장 맞춤 | 불가 (전 가맹점 동일) | **이 매장에 맞춰 조정** |

**영업 멘트 (그대로 카피로 쓸 수 있음)**:
> *"고기 만드는 대표님이 직접 오셔서 사장님 매장 보고 스펙 맞춰드립니다. 프랜차이즈에서 이게 됩니까?"*

> 이건 돈으로 살 수 없는 자산이다. **관계가 곧 무기**이고, 규모가 커져도 경쟁자가 복제할 수 없다.

### "원팩" 표현 — 90 : 10 프레임으로 처리 (2026-07-27 확정)

> 앞 섹션에서 **"원팩의 함정"**을 비판하는데 우리 제품을 원팩이라 부르면 자기모순이 된다.
> → 해법은 [03 §90:10](03_메뉴와-재료.md)과 동일한 프레임이다.

```
공급 90%  ─  브랜드육 스펙·염지·빵가루까지 지정된 상태로 온다
매장 10%  ─  튀김 마무리·담음새·곁들임은 매장의 손
              ▼
      "완제품이 아니라, 90%를 드립니다."
```

> ⚠️ 여전히 **"원팩"이라는 단어 자체는 쓰지 않는다.**
> 앞에서 비판한 단어를 우리 제품에 붙이면 메시지가 흐려진다. → **"90%"**로 대체.

## ⭐ 공급 형태 — 특정하지 않고 '샘플 시식'을 오퍼로 (2026-07-27 확정)

> 사용자 결정: *"돈까스 공급 형태는 **미팅을 통해 샘플링을 통해 직접 체크**합니다."*

이게 미결 항목이 아니라 **오퍼 자체가 된다.**

| 기존 고민 | 전환된 관점 |
|---|---|
| "형태를 정해야 문구를 쓸 수 있는데…" | **형태를 안 정하는 게 맞다.** 매장마다 다르게 갈 수 있으니까 |
| 미확정 = 약점 | **미확정 = 맞춤의 근거** |

### 랜딩에서 이렇게 쓴다

```
❌ "완조리 원팩으로 공급합니다"        ← 형태를 특정하면 맞춤이 아니게 된다
❌ "반조리로 나갑니다"

✅ "사장님 매장 주방에 맞춰 형태를 정합니다."
✅ "샘플 보내드립니다. 직접 튀겨보시고 판단하세요."
✅ "미팅 때 시식하고, 스펙을 그 자리에서 맞춥니다."
```

### 왜 이게 더 센가

| | 형태를 특정할 때 | **샘플링 오퍼** |
|---|---|---|
| 방문자 반응 | "우리 주방엔 안 맞을 것 같은데" | **"일단 먹어보면 되네"** |
| 리스크 부담 | 사장님이 짊어짐 | **우리가 짊어짐** |
| 다음 행동 | 고민 | **문의 → 미팅** ⭐ |
| 스펙 지정 메시지와 | 모순 (맞춤이라며 형태는 고정?) | **일관됨** |

> 📌 **이건 CTA로 직결된다.** 페이지의 목표가 문의 폼 제출인데,
> "샘플 받아보세요"는 "상담 신청하세요"보다 훨씬 낮은 문턱이다.
>
> **카피 후보**
> > "말로 설명하지 않겠습니다. **샘플을 보내드립니다.**"
> > "**직접 튀겨보시고 결정하세요.** 그게 제일 빠릅니다."
> > "겨울 매출 방어선, 한 번 드셔보고 판단하시죠."

> ⚠️ 실무 확인 필요: 샘플 발송 비용·범위를 어디까지 감당할지 내부 기준이 필요하다.
> (무상 발송인지, 지역 제한이 있는지, 미팅 전제인지)
