## 한 장 요약

```
어디서 오나  메타·네이버 광고 / 인스타 / 유튜브  ← 아무것도 모르는 상태로 들어온다
             ↓
누가 보나    ① 시그니처 메뉴가 필요한 기존 식당 사장님   ⭐ 주력
             ② 검증된 밀냉면·밀면을 받아 쓰려는 사장님   ⭐ 주력
             ③ 프랜차이즈는 싫은 창업 예정자            ⭐ 주력
             ④ 대형 리조트·대기업 급식 담당 (간헐)
             ⑤ 자사 브랜드에 접목하려는 본사 (간헐, 산방 이름 사용 불가)
             ↓
무엇을 믿어야 하나
             ① 55년 진짜다          → 01 브랜드 사실
             ② 맛이 진짜 다르다      → 03 메뉴와 재료 (육수·비빔장·생면)
             ③ 내 가게에 붙는다      → 03 확장 메뉴 8종
             ④ 겨울도 버틴다         → 05 초격차 사이드
             ⑤ 묶이지 않는다         → 04 (간판 안 줌 → 로열티 0)
             ⑥ 아무나 못 받는다      → 04 제주 제외 ⭐ 희소성
             ↓
무엇을 하나   문의 폼 작성 → dkfjh1234@gmail.com
```

**페이지의 정체**: **광고·SNS 유입을 문의로 바꾸는 리드 생성 페이지**다.
방문자는 산방식당을 모르는 상태로 들어온다 → **페이지가 처음부터 끝까지 스스로 설명해야 한다.**
