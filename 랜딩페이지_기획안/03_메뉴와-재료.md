## 🧱 3대 자산 — 산방식당이 파는 것의 실체

> 2019년 육지 1호점에서 깨달은 것: **"산방식당의 진정한 힘은 특정 메뉴가 아니었다."**
> 메뉴가 아니라 **육수 · 비빔장 · 생면** 이 셋이 본체다. 이것이 확장 메뉴 전체에 흐른다.

```
        ┌─────────────┬─────────────┬─────────────┐
        │   ① 육수    │  ② 비빔장   │  ③ 생면     │
        │ 국내산 멸치 │ 고운 고춧가루│ 자가제면·생면│
        │  + 생강     │             │             │
        └──────┬──────┴──────┬──────┴──────┬──────┘
               └─────────────┼─────────────┘
                             ▼
        고기국수 · 제육덮밥 · 만두국 · 만두온면 · 고기덮밥
        수육국밥 · 김치찌개 · 낙지비빔밥 …
                             ▼
                   "고객이 느끼는 한끗 맛 차이"
```

| 항목 | 내용 | 검증 |
|------|------|:----:|
| 베이스 | **멸치(생선) 육수** — 돼지뼈·사골 아님 | [확정] |
| 부재료 | **국내산 멸치 + 생강**을 오랜 시간 끓임 | 원문 기재 |
| 맛 | 은근한 단맛 · 짜지 않고 담백 · 적당한 산미 · 개운하고 시원 | [확정] |
| 부산식과 차이 | 부산=구수함(돼지육수) / 제주=**새콤달콤·맑고 시원** | [확정] |

**쓸 수 있는 카피** (원문에 존재):
> "국내산 멸치·생강을 오랜 시간 끓여 제주식 밀냉면의 역사를 만들어온, **시원하고 담백한 육수**"
> "부산과는 다른, 제주만의 밀면"
> "시원함이 살아있는 멸치 육수"

## ② 비빔장 — 고운 고춧가루

| 항목 | 내용 |
|------|------|
| 특징 | **고운 고춧가루** 사용, 과하지 않게 매콤하고 새콤달콤 |
| 용도 | 비빔밀냉면 양념 + **수육 찍어먹는 소스**(겨자와 함께) |
| 평가 | *"이 양념장이 신의 한 수"* — 고기를 찍어도, 냉면에 풀어도 **감칠맛 폭발** |
| 표현 | "달지 않고 짜지 않고, 대단히 상큼하지도 않지만 참으로 입에 잘 맞는" |

> 📌 수육 소스는 **된장·새우젓이 아니라 겨자 + 특제 고추장**이다. 이게 산방식당만의 방식.
> 카피: **"비법 양념장 — 맵지 않아 누구나 즐기는 맛"** / **"수육의 완성은 특제 소스"**

### ✅ 생면 스펙 — 수치까지 자유롭게 사용 가능 (2026-07-27 확인 완료)

> 제조사는 **협력업체**이고, 아래 내용은 **제조사로부터 직접 받은 자료**다.
> **업체명(다선)은 표기할 필요 없다. 다만 내용과 수치는 제약 없이 쓸 수 있다.**

| 스펙 | 내용 |
|---|---|
| **다가수면 — 가수율 45% 이상** | 일반 면은 30~35%. 이미 충분한 수분을 머금은 면은 국물을 더 빨아들이지 않는다 → **안 퍼진다** |
| **자연 숙성** | 일정 시간 자연 숙성 과정을 거쳐 생산 (타사 대비 차별점) |
| **최적 배합비** | 농도에 맞는 배합비로 면발이 탱글탱글 |
| **정제수 사용** | 자체 기술 기준으로 정제한 물만 사용 → 잡냄새 제거 |
| **코셔 천일염** | 이물질·중금속 제거한 천일염만 사용 |
| **HACCP 인증** | 식품안전관리인증기준 적용업소 |
| 생면 제조 **30년** | 전문 제조 경력 |

**그대로 쓸 수 있는 카피 (원문)**:
> **"왜 산방식당 면은 안 퍼지고 오랫동안 쫄깃할까요?**
> 일반 면은 가수율 30~35%. 산방식당 면은 **45% 이상.**
> 이미 충분한 수분을 머금은 면은 더 이상 국물을 빨아들이지 않습니다.
> **끝까지 유지되는 쫄깃함.**"

### 🔴 생면 표현 주의 — "매장에서 뽑는 느낌"을 주지 말 것

| ❌ 쓰지 말 것 | 왜 |
|---|---|
| **"매일 뽑는 생면"** | 매장에서 제면하는 느낌 |
| **"직접 뽑은 면"** | 〃 |
| **"자가제면"** (파트너 매장 맥락에서) | 파트너가 받는 것은 **전문 제조 생면**이다. 본점의 자가제면과 다르다 |

| ✅ 이렇게 | |
|---|---|
| "**생면**" — 건면·냉동면이 아닌 | 사실 그대로 |
| "**가수율 45% 이상의 다가수 생면**" | 스펙으로 말한다 |
| "**자연 숙성 생면**" | |
| "**끝까지 잘 붇지 않는 면**" | 체감으로 말한다 |

> ⚠️ **본점 설명과 파트너 공급을 구분할 것.**

## 🔀 확장 메뉴 — "육지에서는 그 깊이를 나눕니다"

> 검증된 베이스(육수·비빔장·생면) 위에 새로운 조합이 탄생한다. **파트너 매장 전용 메뉴.**

| 메뉴 | 설명 | 어떤 자산이 들어가나 |
|------|------|-------------------|
| **산방고기국수** | 제주 전통 고기국수 | 육수 + 생면 |
| **만두온면** | 따뜻한 육수에 만두 | 육수 + 생면 |
| **만둣국** | 멸치육수 베이스 만둣국 | 육수 |
| **제육덮밥** | 제육볶음 덮밥 | 비빔장 계열 양념 |
| **산방고기덮밥** | 수육 활용 덮밥 | 수육 + 양념장 |
| **수육국밥** | 수육 + 국밥 | 육수 + 수육 |
| **김치찌개** | 돼지고기 김치찌개 | 육수 |
| **낙지비빔밥** | 낙지볶음 비빔 | 비빔장 |

### 📌 이 섹션의 핵심 논리 (사용자 지시 원문)

> *"산방식당의 전통과 맛이 담긴 육수·비빔장·생면이 고기국수, 제육덮밥, 만두국, 만두온면, 고기덮밥 등으로 확장되어 **고객이 느끼는 한끗 맛 차이**를 만들어낸다. **범용적인 원팩으로는 나올 수 없는**, 오랜 시간 끓이고 다리고, 국내산 멸치(육수)와 고운 고춧가루(비빔장), 그리고 생면."*

**대비 구조로 쓸 것:**

| | 범용 원팩 | **산방 베이스** |
|---|---|---|
| 육수 | 농축액 희석 | **국내산 멸치·생강을 오래 끓임** |
| 양념 | 시판 소스 | **고운 고춧가루 비빔장** |
| 면 | 건면·냉동면 | **가수율 45% 이상 다가수 생면** |
| 결과 | "어디서 먹어도 같은 맛" | **"여기서만 먹을 수 있는 맛"** |

> 연결 카피: **"편리함의 함정 — '원팩'이 무너뜨린 '맛의 기준'을 다시 세웁니다."**

## ⭐ 90 : 10 — 이 랜딩의 공급 구조 (2026-07-27 확정)

> 사용자 정의: *"산방식당 공급으로 90%. **10%는 매장에서 약간 노력을 해서** 경쟁력 있는 맛이 만들어진다."*

```
   산방식당이 90%              매장이 10%
   ─────────────              ──────────
   육수                        불 조절
   비빔장                      담음새·고명
   생면                        곁들임 구성
   레시피·조리 교육             매장만의 변주
        │                          │
        └────────────┬─────────────┘
                     ▼
            "여기서만 먹을 수 있는 맛"
```

### 왜 이 구조가 중요한가

| 100% 완제품(원팩) | **90 : 10** | 0% (전부 직접) |
|---|---|---|
| 편하다 | **편하면서** | 어렵다 |
| 어디나 같은 맛 | **여기만의 맛이 된다** | 숙련 필요, 사람 바뀌면 무너짐 |
| 사장님은 데우기만 | **사장님의 손이 들어간다** | 사장님이 다 짊어짐 |

> 📌 **이게 "원팩의 함정"을 비판하면서도 우리 제품이 원팩이 아닌 이유다.**
> 앞에서 원팩을 비판하고 뒤에서 우리 것도 원팩이면 자기모순이 된다.
> **90%는 우리가 책임지고, 10%는 사장님 것으로 남긴다** — 이 구조가 모순을 해소한다.

**카피 방향**
> "완제품을 드리지 않습니다. **90%를 드리고, 마지막 10%는 사장님 손에 남깁니다.**"
> "누가 만들어도 흔들리지 않는 90%. 그리고 이 가게만의 10%."

> 💡 이 프레임은 사장님의 **자존심**도 지켜준다.
> "본사가 다 해준다"가 아니라 "**당신 가게의 맛**"이 되기 때문이다.
> 대상 ③(프랜차이즈 싫은 창업 예정자)에게 특히 강하게 작동한다.

## 사장님이 겪는 문제 (메뉴솔루션 니즈 — 원문)

랜딩 상단 "혹시 이런 고민 중이십니까?" 블록에 그대로 쓸 수 있다:

1. **메뉴 개발의 한계** — 시판 소스로는 차별화가 안 되고, 신메뉴 R&D는 막막하다.
2. **프랜차이즈보다 개인창업** — 내 사업을 하고 싶다.
3. **일관성의 문제** — 주방 인력이 바뀌어도 완벽하게 일관된 '핵심 맛'을 지키고 싶다.
4. **두 번째 시그니처** — 대표 메뉴는 확실한데, 점심 매출·저녁 술손님을 잡을 '검증된 두 번째 메뉴'가 간절하다.
5. **킬러 레시피** — 개인 창업인데 살아남을 '필살기 메뉴'가 막막하다.
