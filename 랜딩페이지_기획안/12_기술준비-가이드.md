# 12. 기술 준비 가이드 — GA4 · 메타 픽셀 · Web3Forms

> 슈퍼보바에서 했던 것과 **같은 절차**다. 그때 쓴 값:
> GA4 `G-Z0RXJY3LPV` · 픽셀 `1529677671894479` · Web3Forms `f8bbd957-…`
>
> ⚠️ **산방식당은 새로 만들어야 한다.** 슈퍼보바 것을 재사용하면 두 사업의 데이터가 섞인다.

---

## 🎯 왜 3개가 필요한가

| 도구 | 없으면 | 30초 요약 |
|------|--------|-----------|
| **GA4** | 몇 명이 왔는지, 어디서 왔는지 **모름** | 방문 측정 |
| **메타 픽셀** | 메타 광고가 **누가 문의했는지 학습 못 함** → 광고비 낭비 | 광고 최적화 |
| **Web3Forms** | 폼이 메일 앱을 여는 방식으로 폴백 → **모바일 이탈** | 폼 전송 |

> ⭐ 특히 픽셀. 메타 광고는 "문의한 사람과 비슷한 사람"을 찾아주는 게 핵심인데,
> **문의가 일어났다는 신호를 못 받으면 그걸 못 한다.** 광고를 돌릴 거면 이건 선택이 아니다.

## 1️⃣ GA4 — 측정 ID 받기

### 계정 구조부터 (여기서 헷갈렸을 것)

```
Google Analytics 계정  (하나면 됨 — 슈퍼보바 만들 때 이미 있음)
   ├── 속성: 슈퍼보바        →  G-Z0RXJY3LPV
   └── 속성: 산방식당  ← 새로 만들 것   →  G-??????????
```

> 📌 **계정을 새로 만들지 말 것.** 기존 계정 안에 **속성(Property)만 추가**한다.

### 단계

1. https://analytics.google.com 접속
2. 좌하단 **관리(⚙️)** → **만들기** → **속성**
3. 속성 이름: `산방식당 랜딩` / 시간대 **대한민국** / 통화 **KRW**
4. 업종·규모 대충 선택 → 만들기
5. 플랫폼 선택에서 **웹**
6. 웹사이트 URL `https://sanbangjeju.com` / 스트림 이름 `산방식당 랜딩`
7. → **측정 ID `G-XXXXXXXXXX`** 가 나온다. **이 값만 복사하면 끝.**

### 코드에 넣기

```ts
// app/src/lib/ui.tsx
export const GA4_ID = "G-XXXXXXXXXX";   // ← 여기
```

> ✅ 스크립트 삽입 코드는 **이미 `App.tsx`에 들어가 있다.** ID만 넣으면 자동으로 붙는다.
> 값이 비어 있으면 조용히 꺼지도록 짜여 있어서, 지금은 그냥 안 붙고 있는 상태다.

### 전환 이벤트 표시 (이걸 빼먹기 쉽다)

폼을 제출하면 코드가 `generate_lead` 이벤트를 쏜다. 그런데 **GA4에서 이걸 "중요한 것"으로 표시해줘야** 보고서에 전환으로 잡힌다.

1. 배포 후 **폼을 한 번 실제로 제출**한다 (이벤트가 한 번은 발생해야 목록에 뜬다)
2. 관리 → **데이터 표시 → 이벤트**
3. `generate_lead` 옆 토글을 켠다
   - UI에 따라 **"전환으로 표시"** 또는 **"주요 이벤트로 표시"** (구글이 이름을 바꿨다)

### 확인

배포 후 GA4 → **보고서 → 실시간**. 본인이 사이트를 열면 1명으로 잡혀야 정상.

## 2️⃣ 메타 픽셀 — 픽셀 ID 받기

### 계정 구조

```
Meta 비즈니스 관리자  (슈퍼보바 때 만든 것 그대로)
   ├── 데이터 소스: 슈퍼보바 픽셀   →  1529677671894479
   └── 데이터 소스: 산방식당 픽셀 ← 새로 만들 것
```

### 단계

1. https://business.facebook.com/events_manager 접속
2. **데이터 소스 연결** → **웹** → 계속
3. 이름: `산방식당 랜딩` → **픽셀 만들기**
4. 설치 방법은 **직접 설치(코드 수동 설치)** 선택 — 파트너 연동 필요 없음
5. → **픽셀 ID (숫자 15~16자리)** 복사

### 코드에 넣기

```ts
// app/src/lib/ui.tsx
export const META_PIXEL_ID = "1234567890123456";   // ← 숫자만
```

> ✅ 스크립트는 이미 들어가 있다. ID만 넣으면 된다.

### ⭐ 도메인 인증 — 이게 진짜 빼먹는 부분

**픽셀만 만들면 반쪽이다.** iOS 개인정보 정책 때문에 도메인 인증을 안 하면 광고 최적화가 제대로 안 걸린다.

1. 이벤트 관리자 → **비즈니스 설정** → **브랜드 가치 보호 → 도메인**
2. **추가** → `sanbangjeju.com`
3. 인증 방법 **3가지 중 택1** — **DNS TXT 레코드가 제일 쉽다** (Cloudflare 쓰고 있으므로)
   - Cloudflare 대시보드 → sanbangjeju.com → **DNS** → **레코드 추가**
   - 유형 `TXT` / 이름 `@` / 내용 = 메타가 준 `facebook-domain-verification=…` 문자열
   - 저장 → 메타로 돌아와 **인증** 클릭
4. 인증되면 **총 이벤트 우선순위 설정**(Aggregated Event Measurement)에서 `Lead`를 1순위로

> 💡 DNS 전파에 몇 분~1시간 걸릴 수 있다. 바로 인증 안 되면 좀 기다렸다 다시 누른다.

### 확인

- Chrome 확장 **Meta Pixel Helper** 설치 → 사이트 열면 픽셀이 잡히는지 표시
- 이벤트 관리자 → **테스트 이벤트** 탭에서 실시간으로 `PageView`·`Lead` 확인

## 3️⃣ Web3Forms — 폼 수신 키

### 단계

1. https://web3forms.com 접속 (**가입 불필요**)
2. 첫 화면 입력칸에 **`dkfjh1234@gmail.com`** 입력 → **Create Access Key**
3. 그 메일함으로 **Access Key(UUID 형태)**가 온다
4. 메일 안의 확인 링크를 눌러 인증

### 코드에 넣기

```ts
// app/src/lib/ui.tsx
export const WEB3FORMS_KEY = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx";
```

> 📌 이 키가 **수신 주소를 결정한다.** HTML에 메일 주소가 직접 안 나타나므로,
> 방문자는 어디로 접수되는지 알 수 없다 → [07 문서](07_문의-접수구조.md)의 "알 필요 없음" 원칙과 맞는다.
>
> ⚠️ **키가 비어 있으면 mailto 폴백이 뜨면서 `dkfjh1234@gmail.com`이 화면에 노출된다.** 반드시 넣을 것.

### 확인

배포 후 폼을 실제로 한 번 제출 → dkfjh1234@gmail.com 수신함 확인 (스팸함도 볼 것).

## 📋 최종 체크

`app/src/lib/ui.tsx` 세 줄이 다음처럼 채워지면 끝:

```ts
export const GA4_ID        = "G-XXXXXXXXXX";
export const META_PIXEL_ID = "1234567890123456";
export const WEB3FORMS_KEY = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx";
```

| # | 항목 | 완료 |
|:-:|---|:---:|
| 1 | GA4 속성 생성 → 측정 ID 입력 | ⬜ |
| 2 | GA4 `generate_lead` 전환(주요 이벤트) 표시 *(배포 후)* | ⬜ |
| 3 | 메타 픽셀 생성 → ID 입력 | ⬜ |
| 4 | **메타 도메인 인증** (Cloudflare TXT) | ⬜ |
| 5 | 메타 이벤트 우선순위에 `Lead` 1순위 | ⬜ |
| 6 | Web3Forms 키 발급 → 입력 | ⬜ |
| 7 | 배포 후 실시간 리포트에 방문 잡히는지 | ⬜ |
| 8 | 폼 테스트 제출 → 수신 확인 | ⬜ |
| 9 | Pixel Helper로 `Lead` 발화 확인 | ⬜ |

> 💡 **1·3·6번(ID 3개 발급)은 사장님이 계정 주인이라 직접 하셔야 한다.**
> 값만 알려주시면 코드 반영·검증은 내가 한다.
